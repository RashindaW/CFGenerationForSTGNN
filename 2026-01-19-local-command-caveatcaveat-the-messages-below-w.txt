  Overview                                                                      
                                                                                
  Your system supports three approaches for counterfactual generation:          
  1. Diffusion-based (original method)                                          
  2. Gradient-based (control/gradient_optimizer.py)                             
  3. Jacobian-based (control/jacobian_controller.py)                            
                                                                                
  All methods operate within an iterative loop where control node inputs are    
  modified to guide predictions toward desired target values.                   
                                                                                
  ---                                                                           
  Gradient Optimization Approach                                                
                                                                                
  Mathematical formulation:                                                     
  X* = argmin_X ||f(X) - Y*||² + λ||X - X_baseline||²                           
  subject to: X_min ≤ X ≤ X_max                                                 
                                                                                
  How it works:                                                                 
                                                                                
  1. Initialize learnable control values from the last timestep of the current  
  window                                                                        
  2. Iteratively optimize (default 100 steps) using Adam or LBFGS:              
    - Forward pass through forecaster to get predictions                        
    - Compute loss = target matching loss + regularization loss                 
    - Backpropagate gradients to control inputs only (forecaster is frozen)     
    - Apply gradient clipping and optimizer step                                
    - Project values onto constraint bounds                                     
  3. Early stopping when loss improvement falls below tolerance                 
                                                                                
  Key features:                                                                 
  - Uses differentiable scatter operations to maintain gradient flow            
  - Regularization encourages minimal intervention (small changes from baseline)
  - Handles various model types (STGCN, GraphWaveNet, etc.)                     
                                                                                
  ---                                                                           
  Jacobian Control Approach                                                     
                                                                                
  Mathematical formulation:                                                     
  For small changes: ΔY ≈ J · ΔX                                                
  Therefore: ΔX ≈ J⁺ · ΔY (pseudo-inverse)                                      
                                                                                
  How it works:                                                                 
                                                                                
  1. Compute Jacobian matrix via backpropagation:                               
    - For each target node, compute gradient of prediction w.r.t. control inputs
    - Result: J matrix of shape (num_targets, num_controls * num_features)      
  2. One-shot linear solve with Tikhonov regularization:                        
  ΔX = (J^T J + λI)^{-1} J^T ΔY                                                 
  3. Apply constraints: max delta clipping and value bounds                     
                                                                                
  Key features:                                                                 
  - Very fast (single linear algebra solve vs. iterative optimization)          
  - Provides interpretable sensitivity analysis (which controls affect which    
  targets)                                                                      
  - Assumes linearity - works best for small changes                            
                                                                                
  ---                                                                           
  Key Differences                                                               
  Aspect: Speed                                                                 
  Gradient-Based: Slow (~100+ iterations)                                       
  Jacobian-Based: Very fast (one-shot)                                          
  ────────────────────────────────────────                                      
  Aspect: Accuracy                                                              
  Gradient-Based: High (handles nonlinearity)                                   
  Jacobian-Based: Approximate (linear assumption)                               
  ────────────────────────────────────────                                      
  Aspect: Large changes                                                         
  Gradient-Based: Handles well                                                  
  Jacobian-Based: Poor (linearity breaks down)                                  
  ────────────────────────────────────────                                      
  Aspect: Interpretability                                                      
  Gradient-Based: Loss convergence curve                                        
  Jacobian-Based: Jacobian reveals sensitivities                                
  ---                                                                           
  Integration in main.py                                                        
                                                                                
  Both methods are accessed via the CausalController class with:                
  - --control_method gradient or --control_method jacobian                      
  - Gradient-specific: --gradient_steps, --gradient_lr, --gradient_reg          
  - Jacobian-specific: --jacobian_reg, --jacobian_max_delta                     
                                                                                
  The iterative counterfactual loop slides a window forward, applying control at
   each step to generate counterfactual trajectories.
